# Zenith OS Updater

Графический обновлятор Zenith OS на базе Debian/Xfce. Он проверяет последний GitHub Release, сравнивает версию с локальной, показывает список изменений, скачивает пакет только вместе с опубликованной SHA-256 суммой, проверяет безопасные пути архива, создаёт резервную копию и запускает установку только после подтверждения пользователя.

## Канал обновлений

По умолчанию приложение проверяет `K8-gh/Zenith-OS` через официальный GitHub Releases API. В релизе должны находиться архив `zenith-os-update-VERSION.tar.gz`, рядом файл `zenith-os-update-VERSION.tar.gz.sha256`, а описание релиза должно содержать список изменений.

## Формат пакета

Архив должен содержать исполняемый `install.sh`. Скрипт установки обязан быть идемпотентным и обновлять только файлы проекта. Перед запуском создаётся резервная копия `/etc/np300e5x/version` в `/var/backups/np300e5x/`. Системные обновления Debian, ядро и драйверы не заменяются этим каналом: для них используются официальные Debian-репозитории.

## Ограничения

Перед публикацией релиза нужно собрать пакет на Debian 13 amd64, проверить его на Live-системе и только затем создавать GitHub Release. Проверка SHA-256 защищает от повреждения или подмены файла, но право публикации в публичном репозитории также должно быть защищено аккаунтом GitHub.
