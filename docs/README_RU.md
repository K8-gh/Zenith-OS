# Zenith OS

## Назначение

Zenith OS превращает чистую установку **Debian 13 amd64 с Xfce** в лёгкую систему с русским интерфейсом и привычной Windows-подобной компоновкой. Он рассчитан на Samsung **NP300E5X-S07RU** с Pentium B970, 6 ГБ ОЗУ, Intel HD Graphics 3000 и NVIDIA GeForce GT 620M.

> Главный принцип стабильности: система должна загружаться на Intel i915 без обязательного проприетарного модуля NVIDIA. GT 620M остаётся доступной через открытый драйвер nouveau, но не принуждается при старте.

## Что входит

| Компонент | Решение |
|---|---|
| Рабочий стол | Xfce: лёгкий, быстрый и настраиваемый |
| Внешний вид | Нижняя панель, меню приложений, рабочий стол и русские названия |
| Браузер | Firefox ESR и русский языковой пакет |
| Wi‑Fi | NetworkManager, firmware-atheros и общий набор firmware |
| Bluetooth | BlueZ и Blueman |
| Видео | Mesa, Intel i915, nouveau для NVIDIA |
| Звук | PipeWire, WirePlumber, pavucontrol |
| Питание | TLP, thermald, powertop |
| Обновления и безопасность | Debian security updates, Gufw, Timeshift |
| VPN | Последний официальный hide.me Linux CLI для amd64, WireGuard и kill-switch |
| Менеджер приложений | Synaptic: поиск, установка, удаление и обновление пакетов |
| Печать и сканирование | CUPS, system-config-printer, simple-scan |

## Требования

Нужны флешка от 8 ГБ, резервная копия личных файлов и подключение к Интернету. Для первой установки рекомендуется соединить ноутбук с роутером кабелем Ethernet или заранее иметь USB-Wi‑Fi/телефон с USB-модемом. Это страховка на случай, если конкретная ревизия Atheros потребует firmware, которого нет на установочной флешке.

Скачайте официальный Debian 13 amd64 с установочным образом, содержащим firmware, и проверьте контрольную сумму. Во время установки выберите Xfce, русский язык, раскладку клавиатуры и установку загрузчика GRUB на системный диск. Если установщик предлагает включить non-free firmware, соглашайтесь.

## Установка

После первого входа откройте терминал и выполните:

```bash
sudo apt update
sudo apt install -y git ca-certificates
cd ~/Загрузки
unzip zenith-os.zip
cd zenith-os
./scripts/install-np300e5x.sh
sudo reboot
```

Если архив распакован в другой каталог, укажите фактический путь к нему. Скрипт не форматирует диск, не удаляет личные файлы и сохраняет резервную копию изменяемых конфигураций. Перед запуском желательно закрыть все приложения.

## Проверка после перезагрузки

Откройте терминал и выполните:

```bash
inxi -Fxxxz
rfkill list
systemctl --failed
```

Ожидается, что графика работает через `i915`, сеть управляется NetworkManager, Bluetooth — службой `bluetooth`, а список failed-служб пуст или не содержит критичных сервисов. Если Wi‑Fi выключен аппаратной клавишей, нажмите Fn-клавишу с антенной и повторите `rfkill unblock all`.

## Wi‑Fi и Bluetooth

Сеть настраивается значком в правой части нижней панели. Для Bluetooth откройте меню приложений → **Настройки → Bluetooth Manager**, включите адаптер, выберите устройство и подтвердите PIN-код. Если Bluetooth не виден, выполните:

```bash
sudo systemctl restart bluetooth
rfkill unblock bluetooth
bluetoothctl show
```

Не устанавливайте случайные Windows-драйверы через Wine или сторонние «Driver Booster». В Linux используются драйверы ядра и пакеты firmware; старые архивы Samsung предназначены для Windows и не являются Linux-драйверами.

## NVIDIA GeForce GT 620M

Система намеренно не делает старый проприетарный драйвер NVIDIA обязательным. Это предотвращает ситуацию, когда после обновления ядра появляется чёрный экран. Для обычного рабочего стола, браузера и фильмов Intel HD 3000 является предпочтительным вариантом. Если нужен второй монитор или проверка 3D, сначала проверяйте открытый nouveau:

```bash
lspci -nnk | grep -A3 -E 'VGA|3D|Display'
glmark2-info 2>/dev/null || true
```

Не переключайте графику и не устанавливайте legacy-пакеты NVIDIA до создания снимка Timeshift. Если тест неудачен, восстановитесь из Timeshift или удалите экспериментальные пакеты из текстовой консоли Ctrl+Alt+F3.

## Внешний вид и главные настройки

Нижняя панель содержит меню приложений, запущенные окна, область уведомлений, звук, сеть, Bluetooth, питание и часы. Через **Настройки → Диспетчер настроек** доступны экран, клавиатура, мышь, темы, рабочий стол, питание и съёмные носители. Через **Настройки → Firewall Configuration** можно включить Gufw и оставить входящие соединения закрытыми по умолчанию.

## hide.me VPN

Установщик получает последний amd64-релиз официального hide.me Linux CLI из публичного репозитория разработчика на момент установки. На момент подготовки комплекта на официальной странице указана версия **0.9.12**; клиент работает через WireGuard и поддерживает защиту от утечек/kill-switch. [6] [7]

В меню появится пункт **hide.me VPN**. Первый запуск попросит создать или ввести Access Token hide.me. Токен не вшивается в ISO и не записывается в комплект, поэтому личные данные пользователя не попадут в установочный образ. Для базовой работы:

```bash
hide.me token
hide.me list free
hide.me connect <сервер>
```

Проверить состояние и справку можно командой `hide.me --help`. VPN не включается автоматически до первой авторизации, чтобы установка не зависела от учётной записи и чтобы пользователь мог сначала проверить обычный Wi‑Fi.

## Менеджер приложений

В меню **Система → Synaptic Package Manager** находится полноценный менеджер Debian-пакетов. Он умеет искать пакеты, устанавливать, удалять и обновлять программы, а также просматривать зависимости и историю операций. [8] Для повседневного использования достаточно искать приложение по названию, отметить его к установке и нажать **Применить**. Перед удалением системных пакетов внимательно проверяйте список зависимостей.

## Обновление без переустановки

Раз в неделю открывайте терминал и выполняйте:

```bash
sudo apt update
sudo apt full-upgrade
sudo reboot
```

Перед большими обновлениями создавайте снимок в Timeshift. Не прерывайте обновление выключением питания. На старом HDD операция может занять заметное время.

## План восстановления

Если рабочий стол не стартует, нажмите Ctrl+Alt+F3, войдите в систему и выполните:

```bash
sudo systemctl restart lightdm
```

Если проблема появилась после эксперимента с NVIDIA, удалите только добавленные экспериментальные пакеты и вернитесь к Intel/nouveau. Если система не загружается, в меню GRUB выберите **Advanced options** и предыдущую версию ядра. Личные документы следует хранить отдельно от системного диска.

## Ограничения

Нельзя честно обещать, что абсолютно каждый компонент заработает без проверки конкретного экземпляра: у NP300E5X встречаются разные ревизии Wi‑Fi-модулей, дисков и BIOS. Поэтому окончательная проверка Wi‑Fi, Bluetooth, камеры, HDMI, сна и регулировки яркости должна выполняться на вашем ноутбуке до удаления старой системы. Zenith OS минимизирует риск и даёт обратимый путь восстановления, но не подменяет тестирование железа.
